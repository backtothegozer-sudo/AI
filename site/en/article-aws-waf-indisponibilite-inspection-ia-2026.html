How to test an AI traffic inspection outage with AWS WAF

Article created November 26, 2026 · Announcement analyzed November 23, 2026 · Source AWS

On November 23, AWS announced general availability of AI Security for AWS WAF. The protection recognizes inference, MCP and A2A traffic, among other types. Content inspection can use Amazon Bedrock Guardrails. Requests pass by default if that service call fails. AWS allows teams to configure the corresponding rule to block them.

1. Reproduce the outage without real data

In a test environment, compare a benign request with and without the inspection service available. Record the filter decision, whether the request reached the application and whether an alert fired. Distinguish an inspection failure from a decision to block content. Verify that logs let you reconstruct the decision without copying the text of the exchange.

2. What changes for Belgian and French organizations

A small business could keep a public FAQ searchable, depending on the risk. At a midsize company handling customer records in Belgium and France, IT and business teams could set up a manual process for confidential exchanges. A public authority could decide which procedures stay available and who can restore normal operations.

3. Underside analysis of data sovereignty

Map what data reaches the filter, where it is inspected and where logs go. Make the same checks for a local model or an on-premises RAG system if its traffic passes through a cloud filter. For an agent connected to Odoo Enterprise, keep access and approval controls in the ERP. Verify in testing that an inspection outage allows no writes outside the approved process.

4. Set conditions for recovery

For each workflow, set an alert deadline, name the decision owner and define when normal operations can resume. Verify that requests processed manually remain traceable and pending operations do not run twice when the service returns.

Before rollout, simulate an outage and agree with the business team whether each workflow continues, pauses or moves to manual processing.
